### [P2] Branch cleanup can remove work added after the PR merge
- Category: material workflow risk
- Rule: `agents/roles/builder.md` §5 cleanup; `agents/START.md` `merged` gate
- Evidence: `agents/roles/builder.md:113-123` permits deleting a local branch when its tip equals the PR's last head **or** `git branch -d` accepts it. `git branch -d` checks whether the branch is merged into its configured upstream, not necessarily `origin/main` ([Git documentation](https://git-scm.com/docs/git-branch/)). This project's feature branches track `origin/<feature-branch>`. A commit made and pushed to that branch after the PR merge passes “no unpushed commits” and can pass `-d` even though it is not part of the merged PR. `agents/START.md:231-234` also says not to edit the active worktree during `merged`, while the new rule permits switching its branch at line 120.
- Failure scenario: PR merges at H; builder commits X on its branch and pushes X; `merged N` proves H merged, sees clean worktree, and `git branch -d` accepts X because `origin/feature` also points to X. Cleanup removes the local branch/worktree containing unmerged follow-up work. The remote branch still holds X, so recovery is possible, but the local context is discarded without warning.
- Why it matters: the new automatic cleanup is meant to remove only work proven merged, and the upstream test does not prove that.
- Required correction: require the local tip to equal the PR's final reviewed head SHA, or prove that the local tip is reachable from the fetched default branch. Do not use `git branch -d` success against an arbitrary upstream as proof. State where cleanup occurs after the log is safely pushed, and align the active-worktree wording in `START.md` with that step.
- Owner: master-kit maintainer, then builder copies the corrected kit into this PR
- Verification: walk through the H→X post-merge scenario and a squash-merge scenario; neither removes an unmerged tip, and a clean final-head branch can still be removed.
- Disposition: before merge
- Status: open
